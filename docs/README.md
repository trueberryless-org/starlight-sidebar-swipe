# `starlight-sidebar-swipe-docs`

Documentation for the `starlight-sidebar-swipe` Starlight plugin, deployed at [starlight-sidebar-swipe.netlify.app](https://starlight-sidebar-swipe.netlify.app).

## Documentation

Run the documentation locally by running the following command in your terminal:

```shell
pnpm run dev
```

Content can be found in the [`src/content/docs/`](https://github.com/trueberryless-org/starlight-sidebar-swipe/tree/main/docs/src/content/docs) directory.
